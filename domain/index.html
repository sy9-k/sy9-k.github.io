SK のサイトは、
sk-hub.jp に引っ越します

SK のサイトとプロダクトのアドレスを、いまの sy9-k.github.io から、新しいドメイン sk-hub.jp に変更します。アドレスの「/」から後ろはそのままです。

いま sy9-k.github.io/toolbox/
これから sk-hub.jp/toolbox/
スケジュール

いつ変わるの？

切り替えの日は、まだ決まっていません。決まったら、このページとサポートのお知らせでお知らせします。

  1. いま 準備中

    新しいドメインの手続きと、引っ越しの準備をしています。いまは、これまでどおり sy9-k.github.io をお使いください。

  2. 切り替え sk-hub.jp で公開

    サイトとプロダクトが sk-hub.jp で開けるようになります。日程は、事前にお知らせします。

  3. 切り替えのあと 古いアドレスから自動で移動

    sy9-k.github.io のページを開くと、当面のあいだ、新しいアドレスの同じページに自動で移動します。

そのまま使えるもの

SK Hub Systems アカウント

アカウントはそのままです。Google・GitHub でのログインも、同期しているデータも引き継がれます。新しいアドレスで、もう一度ログインするだけです。

サービスの中身と料金

使える機能は変わりません。これまでどおり無料です。利用規約とプライバシーポリシーは、アドレスの記載だけを新しくします。

リンクと招待

古いアドレスのリンク・時間割の招待リンクも、新しいアドレスの同じページに移動するので、そのまま使えます。

LINE で使う SK's Toolbox

LINE のミニアプリは、これまでのリンクのまま使えます。

お願い

切り替えのときにしてほしいこと

ブラウザは、端末に保存するデータやログインの状態を、アドレスごとに分けて持っています。そのため、新しいアドレスでは、いくつかやり直しが必要です。

端末に保存しているデータを移す

SK's Toolbox（Todo・Memo・時間割など）、Nagi の記録、MALU の単語帳など、端末にだけ保存しているデータは、新しいアドレスでは最初は空になります。

  • SK Hub Systems で同期している人 … 新しいアドレスでログインすると戻ります。SK's Toolbox の同期を使っている人は、同期用のパスフレーズの入力も必要なので、控えておいてください。
  • 同期していない人 … 切り替えのときに、データをそのまま移す「引っ越し」の機能を用意する予定です。念のため、SK's Toolbox の設定の「まとめてバックアップ」で書き出しておくと安心です（Memo の画像も入ります）。

アプリとして入れている人は、入れ直す

SK's Toolbox・Nagi・MALU をホーム画面やパソコンにアプリとして入れている人は、新しいアドレスで入れ直してください。古いアプリを開くと、入れ直しの案内を出します。

ブックマークを新しくする

古いアドレスからも当面は移動しますが、ブックマークやホーム画面のリンクは、新しいアドレスに登録し直してください。

もう一度ログインする

SK Hub Systems アカウントのログインの状態は引き継がれません。新しいアドレスで、いつもの Google か GitHub のアカウントでログインしてください。

Y-FILTER. は自動で更新

ブラウザ拡張機能の Y-FILTER. は、新しいアドレスに対応した版に自動で更新されます。とくに操作はいりません。

似たアドレスに気をつけてください

SK の公式のアドレスは、sk-hub.jp（とその下のアドレス）と、引っ越しが終わるまでの sy9-k.github.io だけです。skhub.jp・sk-hub.com など、よく似たアドレスは SK とは関係ありません。SK が、メールや SNS でパスワードや個人情報を聞くことはありません。

よくある質問

気になること

どうしてアドレスを変えるのですか？

いまのアドレスは、サイトを置いている GitHub のアカウント名から決まっています。SK のサービスにあった、覚えやすく、ずっと変わらないアドレスで届けるために、独自のドメインに移ります。Google のログイン画面に出るアドレスや、お問い合わせのメールアドレスも、SK のものにそろえていく予定です。

古いアドレスは、いつまで使えますか？

切り替えのあとも、当面のあいだは新しいアドレスへ自動で移動します。移動をやめる場合は、前もってお知らせします。

何もしないと、データは消えますか？

古いアドレスの端末のデータは、すぐには消えません。ただし、新しいアドレスからは見えないので、同期・引っ越しの機能・まとめてバックアップのどれかで移してください。

料金はかかりますか？

かかりません。SK のサービスは、引っ越しのあとも無料です。

わからないことがあれば、お問い合わせからご連絡ください。
