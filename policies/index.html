サイト利用規約

第1条 適用

この規約は、SK（以下「開発者」）が運営するウェブサイト sy9-k.github.io（以下「本サイト」）と、本サイトで提供するウェブアプリ（MALU、Y-FILTER. の管理コンソールなど）の利用に適用されます。プロダクトごとに別の規約がある場合は、そちらが優先します。

第2条 同意

本サイトに初めてアクセスすると、この規約とプライバシーポリシーのお知らせが表示されます。「同意して閉じる」を押した時点、または次にアクセスした時点で、この規約とプライバシーポリシーに同意したものとします。同意しない場合は「同意しない」を押してください。本サイトの一部のページが利用できなくなります。

第3条 禁止事項

本サイトの利用にあたり、次の行為を禁止します。

  1. 本サイトやサーバー（SK Hub Systems）への不正アクセス、過剰なアクセス、アクセス制限を回避しようとする行為
  2. 本サイトの運営を妨げる行為
  3. 他人になりすます行為、他人の権利を侵害する行為
  4. 法令に違反する行為

第4条 アクセスの制限

前条に違反する行為が確認された場合、開発者は事前に通知することなく、該当するブラウザからの本サイトの利用を制限できるものとします。

第5条 外部サイト

MALU などから開く辞書サイト・翻訳サイトは、それぞれの運営者が提供するものです。外部サイトの内容や利用については、各運営者の規約に従ってください。

第6条 免責

本サイトと各プロダクトは現状のまま提供します。開発者は、内容の正確さや、中断・不具合が起きないことを保証しません。本サイトの利用によって生じた損害について、開発者の故意または重大な過失による場合を除き、責任を負いません。

第7条 変更

開発者は、必要に応じてこの規約を変更できます。変更後の規約は、本サイトに掲載した時点から効力を持ちます。

第8条 準拠法

この規約は日本法に従って解釈されます。

プライバシーポリシー

1. 取り扱う情報

本サイトは、サイトの保護（不正な利用への対応）と利用状況の把握のため、次の情報を取り扱います。名前やメールアドレス、IP アドレスは記録しません。

ブラウザの中に保存するものサポートID（ブラウザごとにランダムに作る識別子）、利用規約への同意状態、お知らせを表示したかどうか
サーバーに送信・保存するものサポートID、アクセスしたページの URL（「?」以降は含みません）、移動元サイトのドメイン、ブラウザの種類（ユーザーエージェント）、言語設定、アクセス日時、アクセス制限の判定結果

「同意しない」を選んだ場合、サーバーへの送信は行いません。MALU の検索履歴や設定は、お使いのブラウザの中だけに保存され、サーバーには送信しません。

2. 利用目的

  1. 不正な利用や迷惑行為への対応（アクセスの制限を含む）
  2. 本サイトとプロダクトの利用状況の把握と改善
  3. お問い合わせへの対応

広告、販売、利用者の行動の追跡には使用しません。

3. 保存場所

サーバーに送信した情報は、開発者が運営するサーバー基盤「SK Hub Systems」（Google LLC の Firebase / Cloud Firestore）に保存します。通信は HTTPS で暗号化されます。保存した情報を読み取れるのは開発者だけです。

4. 保存期間

アクセスの記録は、保存から1年を過ぎたものを順次削除します。アクセス制限の情報は、制限を解除した時点で削除します。

5. 第三者への提供

法令に基づく場合を除き、取り扱う情報を第三者に提供しません。

6. 外部サービス

本サイトは次の外部サービスを利用しています。これらのサービスが、アクセスの際に IP アドレスなどを受け取ることがあります。それぞれの取り扱いは各社のポリシーに従います。

  • GitHub Pages（本サイトの配信・GitHub, Inc.）
  • Google Fonts（文字の表示・Google LLC）
  • Google フォーム（お問い合わせ・Google LLC）
  • Firebase（SK Hub Systems・Google LLC）

7. 情報の削除

ブラウザのサイトデータを消去すると、ブラウザの中に保存した情報は削除されます。サーバーに保存した情報の削除を希望する場合は、サポートIDを添えてお問い合わせください。

8. 変更

このポリシーを変更する場合は、本サイトに掲載してお知らせします。取り扱う情報を増やすなど重要な変更の場合は、あらためて同意をお願いします。
