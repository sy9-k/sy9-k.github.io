Y-FILTER.

ブラウザ拡張機能
開発中

有害なサイトのブロックや、1日の利用時間の管理ができるフィルタリング拡張機能です。保護者や学校の担当者が、管理コンソールから複数の端末をまとめて管理できます。

Features

できること

カテゴリとキーワードでブロック

カテゴリごとのブロックリストと、自分で決めたルール・キーワードで、見せたくないサイトを止めます。

利用時間の上限

1日に Web を見られる時間の上限を設定できます。操作も音もない時間は数えません。

許可リスト

勉強に必要なサイトなど、ブロックしたくないサイトは許可リストに入れておけます。

広告ブロック・セーフサーチ

広告のブロックやセーフサーチの強制、ダウンロード・アップロードの制限にも対応しています。

ブロック画面からリクエスト

必要なページがブロックされたら、ブロック画面から管理者に「開けるようにしてほしい」と送れます。

管理コンソールで遠隔管理

ペアリングコードで端末をつなぐと、設定の配信や学習モードの開始を、複数の端末にまとめて行えます。

SK Hub Systems

遠隔管理のしくみ

遠隔管理機能は、SK が運営するサーバー基盤「SK Hub Systems」（Google Firebase）で動いています。閲覧履歴や検索語は送信・保存しません。取り扱う情報の詳細は利用規約をご覧ください。
